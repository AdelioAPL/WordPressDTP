
# Docker Compose - WordPress + MySQL

## Deskripsi
Project ini menjalankan aplikasi WordPress
yang terhubung dengan database MySQL
menggunakan Docker Compose.

## Teknologi
- Docker
- Docker Compose
- WordPress
- MySQL 8.0

## Cara Menjalankan
1. Pastikan Docker sudah berjalan.
2. Pastikan file .env sudah dikonfigurasi.
3. Jalankan:

   docker compose up -d

## Akses Aplikasi
http://localhost:8080

## Menghentikan Aplikasi
docker compose down
